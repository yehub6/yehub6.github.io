功能与实现

D09 列出学习、练习、题库导入、家长管理和里程碑庆典。S17 处理 Game Center 登录及断开状态；S18 对应本机 macOS 数字 App ID。正常游戏进度或家长验证引起的入口差异需要说明，不能笼统声称任何时刻画面完全一致。

联网用途与边界

可选 Game Center 使用 Apple 服务。用户选择的系统分享或云文件来源也应按实际版本说明；本次没有将全部系统路径判定为离线。

复现步骤（尚待对应构建录屏）

  1. 正常启动 macOS 版本，完成一节课与一个练习或游戏。
  2. 展示本地结果、家长控制和自有文本题库导入。
  3. 解释模式开放与庆典条件，并记录 Game Center 断开状态。

待补充证据

macOS 1.0.3 实际 Build 和 Bundle ID 仍需后台核对。若 iOS 独立列为另一记录，不自动共用其 Apple ID 或版本。

Functionality and implementation

D09 lists lessons, practice, content import, parental controls and milestone celebrations. S17 handles Game Center authentication and disconnected states; S18 identifies the local macOS numeric App ID. Normal progression and parental gates require activation instructions, not a blanket claim of identical screens at every moment.

Network purposes and boundaries

Optional Game Center uses Apple services. User-selected sharing or cloud-file providers also need version-specific disclosure; not every system path is assumed offline.

Reproduction steps (Build-matched recordings still required)

  1. Launch the macOS build normally and complete a lesson and a practice/game mode.
  2. Show local results, parent controls and import of an owned text library.
  3. Explain mode/celebration conditions and record disconnected Game Center behavior.

Evidence still required

The macOS 1.0.3 Build and Bundle ID still need backend confirmation. A separate iOS record must not automatically inherit the same Apple ID or version.
