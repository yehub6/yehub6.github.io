简体中文

功能与实现

D03 列出本机计算、OCR、主题与系统扩展。S11 解析 ECB XML 中的日期、币种和数值，支持缓存；在所检查路径中，响应是参考汇率数据，不是可执行代码或改变产品用途的指令。

联网用途与边界

S11 向 ECB 公开地址请求汇率，所检查的请求未包含用户输入的计算金额。这只是该路径的观察，不能外推整款 App 无网络；参考汇率也不是实时交易报价。

复现步骤（尚待对应构建录屏）

  1. 离线进行计算，并扫描和确认一个表达式。
  2. 展示汇率来源、数据日期，联网刷新。
  3. 断网使用已缓存汇率，并展示实际 Build 中的系统扩展入口。

待补充证据

需对应 1.0.0 实际 Build，核对扩展、权限和实际提交说明，补齐普通安装录屏及网络记录。

English

Functionality and implementation

D03 describes local calculation, OCR, themes and system extensions. S11 parses dates, currency codes and numeric rates from ECB XML and supports caching. In this inspected path the response is reference data, not executable code or instructions to change the product.

Network purposes and boundaries

S11 requests public ECB rates without including the entered calculation amount in the inspected request. This is a path-limited observation, not a network-free claim for the app. Reference rates are not live trading quotes.

Reproduction steps (Build-matched recordings still required)

  1. Calculate offline, then scan and confirm an expression.
  2. Show the rate source/date and refresh online.
  3. Use cached rates offline and show extensions present in the actual Build.

Evidence still required

Match the actual 1.0.0 Build, verify extensions/permissions and submitted disclosures, and add normal-install recordings and traffic records.
