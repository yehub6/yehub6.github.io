计算器 - 高精度计算工作台

Apple ID 6809879246

对应技术证据 / App-specific technical evidence

Supplementary statement

This entry concerns the September 11, 2026 account-level Pending Termination Notice under section 3.2(f), not merely an ordinary version rejection. 计算器 - 高精度计算工作台, Apple ID 6809879246, com.calculatorx; version 1.0.0 was waiting for review.

I have not deliberately hidden functionality, given reviewers a different product to evade review, or arranged a post-approval switch to another service.

Current source and review materials describe local calculation, OCR, currency conversion and Apple system extensions. The currency tool downloads public European Central Bank reference-rate XML. The inspected provider parses dates, currency codes and numeric rates and supports cached data. That path consumes reference data, not executable code or instructions to change the product. The inspected request does not include the amount entered for calculation. This observation is limited to that path.

Review can perform a calculation offline, scan and confirm an expression, inspect the rate source/date, refresh online, and use the cached snapshot offline. Rates are reference data, not live trading quotes. This app is not represented as entirely network-free.

Before further submissions I will match current-source features to the submitted Build, preserve records, provide normal-launch recordings and network explanations, document extensions and permissions, and verify that localized metadata, screenshots, privacy information and review notes describe the same actual functionality. I will correct confirmed inaccuracies and record future feature changes specifically for review.

This entry belongs to the same nine-app membership appeal. Please identify the affected Build, entry point and observed conduct, reconsider termination, and allow targeted evidence or correction and renewed review where appropriate.
