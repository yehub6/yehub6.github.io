Getting Started

键盘星球使用教程

适用于 macOS 14.0 或更高版本

1. 从首页开始

打开应用后，可直接进入“星星花园”或“键盘练习场”。第一次使用建议选择“彩虹入门”难度，先熟悉中间排按键。

2. 选择键盘布局

在开始练习前选择与设备一致的苹果或 Windows 键盘外观。屏幕键盘会同步高亮当前需要按下的键。

3. 使用指法提示

点击手指摆放提示，先认识 F/J 基准键；八指分色会告诉孩子每个按键由哪根手指负责。无需追求速度，先保证按键准确。

4. 逐步挑战更多模式

“更多模式”中包含英文单词、短句、数字与符号、中文拼音等内容。中文玩法请切换到 ABC / 英文输入法，按无声调拼音输入。

5. 查看成长记录

练习结束后，可在成长记录里查看练习局数、正确按键数与练习时长。Game Center 为可选功能，不登录也可以正常练习。
