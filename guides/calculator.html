计算器使用教程

版本 1.0.0 · iPhone / iPad · 更新日期：2026 年 9 月 9 日

1. 从一次计算开始

在「计算」页选择所需模式，输入表达式并按等号。科学计算前核对角度模式；标准模式与表达式模式的百分比语义可能不同。打开结果审计查看运算步骤、精度、近似标记和舍入规则。显示位数可在设置中调整为 6–50 位有效数字，显示位数不等于所有运算都精确到该位数。

2. 把重复计算变成工作台

进入「工作台」新建文档，按顺序添加变量和表达式。例如：

rent = 4200
utilities = 286
rent + utilities

最后一行得到 4486。改变前两行的输入，下游表达式随之重算。通过标题、文件夹和标签整理文档；导出可分享的计算内容。变量应先定义再使用，遇到错误请先修正出错行。

3. 拍照识别与金额汇总

  1. 进入「工具箱 → 拍照计算」，选择拍照、照片、导入图片或 PDF，也可以主动粘贴图片。
  2. 选择算式、金额列表、票据或表格数字模式。PDF 当前只识别第一页，不是整份多页扫描。
  3. 检查识别文字、置信度、正负号、小数点与单位，编辑错误文字并勾选需要的行。低置信度内容默认不参与。
  4. 点击「确认并计算」。可继续在计算器编辑或分享结果；原图默认不保存，确认计算后保存识别及校正文字。

4. 函数图与分析工具

在「工具箱 → 函数图」输入关于 x 的表达式，点击绘制，按需使用求根、导数、积分和重置视图。通过导出菜单保存 CSV、PNG 或 PDF。数值分析是近似计算，需要核对定义域与输入范围；不支持的表达式会显示错误。

其他工具提供单位、参考汇率、日期、工作日、贷款、复利、统计回归、矩阵和方程。汇率页会展示来源及日期，联网失败会回退到有日期的离线快照，不能视为实时交易报价。

5. 选择完整主题

进入「设置 → 主题皮肤」，在独立页面选择六款皮肤之一。背景、卡片、按键、文字和状态色整体切换，主题保存后供 Widget、分享扩展和计算器键盘读取。小组件刷新由系统调度；扩展若仍显示旧外观，关闭后重新打开。

6. 接入系统工作流

添加主屏幕 Widget，或在「快捷指令」中搜索计算器的计算表达式、打开模式、收藏公式、单位转换及扫描入口。扫描动作打开应用中的识别流程，不会在后台悄悄拍照。iOS / iPadOS 18+ 可添加控制中心控件。

在系统分享面板选择计算器，处理文字、网址文本、图片或一个 PDF 的第一页。分享扩展不打开网址抓取网页；保存的结果会排队，主 App 下次打开时写入记录。键盘在系统「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」启用，通过地球键切换，按等号把结果插入当前文本框；无需开启完全访问。

7. 本地数据与备份

在「设置 → 本地备份与恢复」导出备份到文件 App。导入会校验格式和数量，按稳定 ID 合并，相同 ID 的现有项目保留本机版本。备份没有额外文件加密，应存放在可信位置。

数据默认保存在本机。可选 iCloud 开关在下次启动时尝试启用私人数据库，需要 Apple 账户、网络及正确配置的版本；检查设置中的存储状态。关闭开关不会自动删除原有云端副本。更换设备或卸载前请先导出备份。

User guide

Calculation and worksheets

Choose a mode in Calculator, enter an expression and evaluate it. Check the angle mode and percentage semantics, then inspect the result audit for steps, accuracy and rounding. Settings supports 6–50 displayed significant digits; display precision is not a guarantee that every operation is exact to that many digits.

Create a worksheet and define variables before using them. The example above totals 4486; changing rent or utilities recalculates dependent lines. Organize documents with names, folders and tags, and use export to share your work.

Scan and calculate

Open Toolbox → Scan & Calculate, then choose Camera, Photos, an image/PDF file or an explicit paste action. PDF import processes the first page only. Select an expression or amount-based mode, review confidence and punctuation, correct text and select the intended lines before confirming. Low-confidence lines are not selected by default. Original images are not saved by default; recognized and corrected text is saved when calculation is confirmed.

Plots, conversion and analysis

Enter a function of x and plot it, then use root, derivative, integral, reset or CSV/PNG/PDF export. Numerical analysis is approximate: check domains and ranges. Conversion, dates, loans, interest, statistics, regression, matrices and equations are available in the toolbox. Currency data is dated reference information, with an offline fallback, not a live trading quote.

Themes and system integrations

Open Settings → Theme Skins to select one of six complete skins. Themes are also shared with widgets, the share extension and calculator keyboard; reopen extensions if necessary and allow the system time to refresh widgets. Search for Calculator in Shortcuts to calculate, open a mode or formula, convert units or open scanning. Control Center controls require iOS / iPadOS 18+.

The share extension accepts text, URL text, images or the first page of one PDF. It does not fetch webpages. Saved results are queued for the next main-app launch. Enable the keyboard in system Settings → General → Keyboard → Keyboards → Add New Keyboard. Switch with the globe key and press equals to insert the result. Full Access is not required.

Backup and optional iCloud

Export a backup from Settings → Local Backup & Restore. Import validates the file and merges by stable IDs, preserving existing local items with the same IDs. Backup files have no additional encryption. Store them securely and export before uninstalling or migrating. Optional private iCloud storage is attempted on the next launch and depends on your Apple account, connectivity and app configuration. Check the storage status; turning it off does not delete existing cloud copies.

8. 分享 App 与评分邀请

进入「设置 → 支持与分享」，点「分享 App」打开系统分享面板，发送的是 App Store 链接，不包含计算记录。点「前往 App Store 评价」打开评价页，正式上架后可用。自动邀请须至少使用 3 天、跨 3 个日期完成 10 次计算，再等待 8 秒无操作；输入、切页、弹出面板或进入后台会取消当前等待。每版本最多请求一次、至少间隔 120 天，365 天内最多请求 3 次。关闭「自动评分邀请」立即停止后续自动请求。

In Settings → Support & Sharing, Share App opens the system share sheet with the store link, without calculation records. Rate on the App Store opens the review page after release. Automatic requests require at least three days since first use, ten completed calculations across three UTC dates, and an eight-second pause. Editing, navigation, sheets or backgrounding cancel the pending request. Limits: once per version, at least 120 days apart, at most three requests per rolling 365 days. Turn the option off at any time.
