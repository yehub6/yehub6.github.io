轻扫 PDF 使用教程

适用于 v1.0 · iPhone 与 iPad · iOS / iPadOS 17.0+

应用介绍技术支持隐私政策

1. 扫描或导入文档

在首页选择“开始扫描”可使用系统文稿扫描器。选择“导入文件”后，PDF 会直接进入文档查看与编辑界面；选择“导入图片”后，会进入图片转 PDF 流程，而不是只显示导入成功提示。

2. 整理文件

在“文件”页面按名称搜索，通过类型筛选、排序、收藏和文件夹整理文档。删除后的文件进入“最近删除”；应用会核对文件是否仍然存在，避免重复删除造成错误提示。

3. 修改 PDF 文字

打开 PDF 后进入“编辑文字”或“查找替换”。对于包含文字层的 PDF，应用会读取文字位置、大小和颜色并在原位置替换；你也可以手动选择字体、字号、颜色、对齐方式和背景覆盖参数。扫描件需要先运行 OCR，识别准确度取决于清晰度、字体和版式。

4. 填写与签署

选择“纸面签署”，从 PDF、图片、照片、相机或文稿扫描导入纸张。可添加手写、签名、文字、日期、勾选、印章、指纹、高亮和形状，并拖动或缩放到正确位置。完成后先查看最终预览，再导出 PDF、PNG 或 JPEG。

5. 使用 PDF 工具

“工具”页面提供图片转 PDF、OCR、扫描、合并、拆分、提取页面、页面管理、压缩、水印、签名、密码保护与解除密码等功能。按工具提示选择输入文件并确认输出位置即可。

6. 导出与分享

编辑完成后可保存为新文件，或通过系统分享面板发送到“文件”、邮件、信息或其他已安装应用。分享目标收到的内容由用户主动选择，应用不会自动上传文档。

7. 隐私与保护

设置中可开启启动验证、保护签署素材，并管理存储空间、最近删除和缓存。Face ID、Touch ID 或设备密码验证由 Apple 系统完成，应用不会读取生物识别数据。

如文字替换位置或格式不准确，请保留原 PDF，并将“页码、原文字、目标文字、设备型号和系统版本”发送至支持邮箱，便于定位版式问题。
