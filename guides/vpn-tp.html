User Guide

VPN TP 使用教程

适用于 v1.0.2（Build 3）· iPhone、iPad 与 Mac · iOS / iPadOS 16.0+ · macOS 13.0+

应用介绍技术支持隐私政策

1. 添加安全展示数据

首次体验可打开“设置 → 展示数据”，点击“添加安全示例”；工作台空状态也提供相同入口。应用会在本机加入 11 条结构真实的演示配置，只使用保留域名、文档专用 IP 和无效测试凭据，不包含可用节点或实时订阅。

2. 一键导入并按订阅分组

在“导入订阅 URL”中输入你有权使用的公网 HTTPS 地址并点击“一键导入并分组”，App 会直连该服务商，识别 URI 列表、整包 Base64、Clash YAML 或 Sing-box JSON，立即保存可识别节点并自动创建独立来源分组；结果弹窗可直接打开该分组。再次导入同一订阅会更新其中的匹配节点；不同订阅即使包含相同节点，也分别保留在各自分组。需要逐项筛选时可点击“仅预览”。粘贴配置文本、扫描二维码、选择二维码照片和系统文件也支持直接导入。订阅下载不支持 HTTP、本机/私网地址、后台刷新或超过 10 MB 的响应；仅含 proxy-providers 外部引用而没有节点的 YAML 会明确提示，不会静默递归下载其他地址。

3. 查看详情与整理配置库

点击工作台底部“最近编辑”或配置库中的任意列表/卡片，即可进入配置详情，查看基本信息、传输、验证、未知字段和原文入口，并继续编辑、复制、分享或删除。订阅节点会显示所属来源分组和脱敏 URL；路径或查询中的疑似 Token 会隐藏，完整订阅 URL 不会写入数据库。在配置库还可搜索、收藏、分组和添加标签。普通结构元数据保存在本机数据库，密码、Token、私钥、证书与完整原文等敏感内容由系统钥匙串保护。

4. 查看订阅差异与加密历史

打开“订阅中心”可查看所有来源、节点数、平均健康度和最近变化。每次手动更新都会创建本机 AES-GCM 加密快照，最多保留每个来源最近 12 份；选择两个快照可查看新增、移除和修改，也可明确确认后回滚。异常提醒只在你手动更新后本地判断，不会自动或后台请求订阅。

5. 健康评分、结构视图与智能修复

打开“配置健康度”可查看每份配置的分数、等级和问题列表。详情中的结构视图按来源、协议、脱敏端点、传输、安全、认证和高级字段分层显示。智能修复会规范化名称、地址、路径和 UUID，清理空字段及重复标签；保存前会列出实际变化。

6. 使用安全多帧二维码

在“安全二维码传输”中选择一份配置并设置独立密码，App 会在本机加密后拆成带编号和校验的多帧二维码。接收端可连续扫描、乱序收集或一次选择多张图片；只有帧完整、校验一致且密码正确时才会恢复。不要通过不可信渠道同时发送二维码和密码。

7. 分享前脱敏

进入“工具 → 配置脱敏”，选择轻度、标准或完全等级。预览确认后再复制或导出；普通 JSON / CSV 导出默认排除敏感字段。分享前仍应人工确认接收方与最终内容。

8. 比较与格式转换

“配置比较”会将两份配置映射为统一字段，并默认隐藏敏感字段变化。“格式转换”会在输出前列出无法转换、将被忽略或需要确认的字段，避免把格式差异误认为完整兼容。

9. 创建加密备份

在“设置 → 创建加密备份”设置独立密码并保存导出文件。完整备份使用密码派生与 AES-GCM 加密，应用不会保存或找回备份密码；恢复时需要输入创建备份时的同一密码。

10. 使用小组件与 App 快捷指令

iPhone/iPad 小组件显示配置数、来源数、健康数量和需处理数量等本机汇总，不显示名称、节点地址、订阅 URL、凭据或原文；点击可进入订阅中心。系统快捷指令可直达订阅中心、配置健康、安全传输和导入中心。

11. 切换 App 语言

打开“设置 → 通用 → App 语言”，可选择“跟随系统”、English、简体中文、繁體中文、日本語、한국어、Español、Français、Deutsch、Русский 或 فارسی。选择后界面立即更新，并保存在当前设备上；选择波斯语时界面自动切换为从右向左布局。

12. 在 Mac 上使用

Mac 版稳定侧栏可直接进入工作台、配置库、导入、工具和设置。可将配置文件、订阅 URL 或节点文本拖到导入页；Finder 选中支持的配置文件后按空格，可查看本机生成的脱敏预览。右上角菜单栏使用 VPN TP 正式图标，提供页面直达、配置统计、安全示例和退出；Command-1 至 Command-5 切换页面，Command-Shift-D 载入安全示例。

13. 网络检查的边界

DNS、TCP 端口和 TLS 证书检查只会访问你主动输入的目标，用于显示基础状态。VPN TP 不使用 NetworkExtension，不创建系统 VPN 配置，不代理或转发网络流量，检查结果也不构成可用性或安全保证。

14. 广告与隐私选择

免费 iPhone 与 iPad 版使用 Google AdMob 展示横幅、原生、插页和开屏广告。应用每次启动都会先通过 Google UMP 更新适用的隐私状态，仅在允许请求广告后请求 Apple ATT，并等待 ATT 结果再初始化广告 SDK。同时允许 UMP 个性化用途与 ATT 时，Google 可为符合条件的请求提供个性化广告；拒绝 ATT 或个性化用途时，仍可依据 UMP 状态展示不使用 IDFA 的非个性化、受限或技术投放广告，且不会限制配置功能。导入的配置和凭据绝不会用于广告。在“管理广告隐私”中修改选择后，App 会清除旧广告并按最新选择重新请求。原生 Mac 版无广告，也不请求 ATT。

15. 分享、评价与反馈 VPN TP

进入“设置 → 关于”，点击“分享 VPN TP”可通过系统分享面板发送正式 App Store 页面；“为 VPN TP 评分”会调用 Apple 系统评分界面；如需撰写文字评论，可点击“前往 App Store 写评价”直达 App Store 评论页。点击“技术支持与反馈”会打开系统邮件 App，固定收件人为 2223140373@qq.com，并自动预填 App 版本和系统版本；App 不会自动附加配置、凭据或诊断文件。App 还会在至少 3 次独立使用、完成 3 次导入、保存、导出或备份等有效操作，并且首次使用满 48 小时后，智能请求一次系统评分；同一版本最多请求一次，跨版本至少间隔 120 天。是否真正显示评分窗口仍由 Apple 系统决定。相关商店入口均使用 Apple App ID 6806803997。

发送问题反馈前，请先对配置进行完全脱敏。建议保留邮件中预填的 App 与系统版本，并补充设备型号、输入格式和可复现步骤；不要发送真实密码、Token、私钥、PSK、证书或可用配置。
