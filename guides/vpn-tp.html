User Guide

VPN TP 使用教程

适用于 v1.0 · iPhone、iPad 与 Mac · iOS / iPadOS 16.0+ · macOS 13.0+

应用介绍技术支持隐私政策

1. 添加安全展示数据

首次体验可打开“设置 → 展示数据”，点击“添加安全示例”；工作台空状态也提供相同入口。应用会在本机加入 11 条结构真实的演示配置，只使用保留域名、文档专用 IP 和无效测试凭据，不包含可用节点或实时订阅。

2. 导入并检查配置

进入“导入”，粘贴文本、扫描二维码，或通过系统文件选择器选择配置文件。点击“识别并检查”后，应用会逐项显示格式、重复项、解析失败、结构错误与风险提示，再由你决定保存哪些项目。

3. 整理配置库

在“配置库”查看、搜索、收藏、分组、添加标签、编辑或删除已保存项目。普通结构元数据保存在本机数据库，密码、Token、私钥、证书与完整原文等敏感内容由系统钥匙串保护。

4. 分享前脱敏

进入“工具 → 配置脱敏”，选择轻度、标准或完全等级。预览确认后再复制或导出；普通 JSON / CSV 导出默认排除敏感字段。分享前仍应人工确认接收方与最终内容。

5. 比较与格式转换

“配置比较”会将两份配置映射为统一字段，并默认隐藏敏感字段变化。“格式转换”会在输出前列出无法转换、将被忽略或需要确认的字段，避免把格式差异误认为完整兼容。

6. 扫描或生成二维码

扫描功能仅在你主动打开时请求相机权限，也可从系统照片选择器读取明确选择的图片。生成二维码默认使用脱敏内容；若选择包含敏感字段的内容，应用会显示警告并请求 Face ID、Touch ID 或设备密码验证。

7. 创建加密备份

在“设置 → 创建加密备份”设置独立密码并保存导出文件。完整备份使用密码派生与 AES-GCM 加密，应用不会保存或找回备份密码；恢复时需要输入创建备份时的同一密码。

8. 切换 App 语言

打开“设置 → 通用 → App 语言”，可选择“跟随系统”、English、简体中文、繁體中文、日本語、한국어、Español、Français 或 Deutsch。选择后界面立即更新，并保存在当前设备上。

9. 在 Mac 上使用

Mac 版左侧边栏可直接进入工作台、配置库、导入、工具和设置，并支持调整窗口大小。右上角菜单栏使用 VPN TP 正式图标，点击后可快速跳转页面、查看配置统计、添加安全示例或退出；菜单命令还提供 Command-1 至 Command-5 页面快捷键，Command-Shift-D 可载入安全示例。

10. 网络检查的边界

DNS、TCP 端口和 TLS 证书检查只会访问你主动输入的目标，用于显示基础状态。VPN TP 不使用 NetworkExtension，不创建系统 VPN 配置，不代理或转发网络流量，检查结果也不构成可用性或安全保证。

发送问题反馈前，请先对配置进行完全脱敏。建议附上设备型号、系统版本、App 版本、输入格式和可复现步骤，不要发送真实密码、Token、私钥、PSK 或证书。
