1. What the app does

Vidma is an on-device video editor and media utility that supports trimming, splitting, merging, rotating, resizing, reversing, freezing, filtering, background, blur/mosaic effects, subtitles, overlays and batch operations. It also supports extracting/mixing audio, GIF rendering, frame capture, media info inspection, and format conversion among supported container/codecs.

2. Physical-device recording

A public recorder is being prepared for upload in App Store Connect Resolution Center. Current repository test evidence includes simulator and on-device validation logs and exported proof assets. If requested, a fresh physical-device recording can be attached after the next signed build upload.

3. Tested devices and operating systems

  • iPhone 14 Pro (iPhone15,2) — iOS 26.6 — physical device
  • iPhone 16 Pro (simulator)
  • iPad Pro 11-inch (simulator)

Media matrix checks cover H.264/AAC, HEVC, portrait and landscape formats, long-form reverse export, subtitle burn-in parity, and task-queue continuity.

4. Access and setup instructions

  1. Launch Vidma and import one local video from Photos or Files.
  2. Open an editor module (trim/speed/reverse/overlay/subtitle/audio).
  3. For subtitle test, use one clean spoken-audio sample and open the caption module.
  4. Run export with default settings, then confirm playback in an external player and inside the app.
  5. Test “keep original audio / muted / imported music” branches in reverse flow.
  6. Open Settings for permission toggles and cache cleanup.
  7. Use “Save to Photos” and “share” actions only after explicit completion.

5. External services and permissions

Vidma uses Apple frameworks and system services only: Photos, Files access when initiated by user, AVFoundation, Core Image, AVSpeech / Speech framework, and local notifications. There are no ad, analytics, account, payment, or third-party media upload services.

6. Region / device limitations

The app uses on-device speech assets and may vary by OS, region and language pack availability. Songs/lyrics scenes and heavy-noise samples are expected to produce limited subtitle quality and are presented as such in UI copy.

7. Data disclosure

Vidma is a local-first app. No account creation, no registration, no tracking SDK, and no developer server upload of user media are implemented in this reviewed build.
