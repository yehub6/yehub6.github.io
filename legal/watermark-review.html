3. Functions, target audience, problem, and value

Watermark Camera is a Simplified Chinese, local photo-watermarking camera for users who need a clear record of when and where a photo was taken, including field workers, property and service staff, construction and inspection personnel, delivery personnel, travelers, and general users.

Users can take a new photo or import an existing photo, then add date, time, weekday, coordinates, detailed address, nearby place name, device model, and custom text. Watermark color and corner position are editable. The local works gallery supports viewing, editing, saving, sharing, and deleting.

The app provides a quick, account-free way to make work records and everyday photos easier to identify and verify. Photos, generated works, and settings are stored locally on the device.

4. Setup and access instructions

No account, login credentials, demo account, subscription, purchase, special configuration, or sample file is required.

  1. Launch the app and tap Shoot (拍摄) on the Home screen.
  2. Allow Camera access. To test detailed-address and nearby-place watermarks, allow Location While Using the App and enable Precise Location.
  3. Take a photo, review the generated watermark, and tap Save to Photos (保存到相册). Allow Add Photos access when requested.
  4. Return to Home and tap Import (导入) to select any image available through the system photo picker.
  5. Open Gallery (相册) to view, edit, share, save, or delete local works.
  6. Open Settings (设置) to change watermark content, style, grid, app sharing, rating, privacy information, and User Feedback.

If Location access is denied, the camera, importing, and all non-location watermark features remain available. The system photo picker exposes only the image explicitly selected by the reviewer.

5. External services, tools, and platforms

The app has no third-party SDK, developer-operated backend, advertising service, analytics service, AI service, authentication provider, payment processor, subscription service, or cloud storage.

It uses only Apple-provided frameworks and system services:

  • Apple AVFoundation for camera capture
  • Apple Core Location for the current coordinates
  • Apple CLGeocoder and MapKit local search for detailed-address and nearby-place results
  • Apple PhotosUI and PhotoKit for user-controlled photo selection and saving results
  • Apple UIKit system share sheet for user-initiated sharing
  • Apple MessageUI or the user's installed Mail app for optional feedback
  • Apple StoreKit for the system App Store rating request

All watermark composition and photo editing are performed locally. Location queries needed for detailed addresses and nearby places are handled by Apple system services; the developer does not receive them and operates no server.

6. Regional differences

The app's core functions are available consistently in all regions, with no region-locked features or region-specific paid content. The current interface is Simplified Chinese. Address language and the level of nearby-place detail can vary according to Apple Maps coverage, local map data, device language, and location accuracy.

If a detailed place name is unavailable, users can still use date, time, weekday, coordinates, device information, and custom-text watermarks.

7. Regulated industry and protected third-party material

The app is a general camera and photo-editing utility. It does not provide medical, financial, legal, gambling, transportation-booking, or government services. It does not bundle, sell, stream, or publish protected third-party material.

The app processes only photos captured by the user or explicitly selected by the user through the system photo picker. No regulatory authorization, third-party license, demo account, or external credential is required.
