0. App Tracking Transparency · Guideline 5.1.2(i)

Version 2.0.0 preserves Apple's App Tracking Transparency authorization flow. On a clean install, any required Google UMP consent form is completed first. The iOS ATT system prompt is then presented before Google Mobile Ads SDK initialization and before any ad request. IDFA is available only when the user authorizes tracking. Denying or restricting tracking does not gate any app feature.

Review location: clean-install and launch the app. If a UMP form is shown, complete it. The ATT system prompt appears next, before the app-open ad or the main app interface.

1. WeatherKit attribution · Guideline 5.2.5

Weather is an optional watermark field and is off by default. The replacement build adds a dedicated Apple Weather attribution block to both Settings → Watermark Content and Settings → Privacy & Security. The block clearly displays the Apple Weather trademark ( Weather) and a visible Data Sources link.

Review path:

  1. Launch the app and open Settings (设置).
  2. Open Watermark Content (水印内容). The Apple Weather attribution block is shown with  Weather and Data Sources (数据来源).
  3. Tap Data Sources. The app opens the legal attribution URL supplied by WeatherService.shared.attribution.legalPageURL. If Apple does not return that URL, the app uses Apple's official WeatherKit legal-attribution page: weatherkit.apple.com/legal-attribution.html.
  4. The same attribution block can be verified in Settings → Privacy & Security (隐私与安全).

The weather request uses Apple WeatherKit only after the user enables weather content and Location permission is available. A failed weather request hides the optional weather field and never prevents photo or video capture.

The same recording should be attached to the App Store Connect Resolution Center response and referenced in App Review Information → Notes. Before archiving, the submitted App ID and provisioning profile must include the WeatherKit capability and the signed app must contain the com.apple.developer.weatherkit entitlement.

4. Functions, target audience, problem, and value

Watermark Camera is a Simplified Chinese and English, local-first professional photo-and-video watermarking camera for users who need organized visual records, including field workers, property and service staff, construction and inspection personnel, travelers, families, and general users.

Users can capture or import photos and videos, use ten original shared templates, edit media non-destructively, organize work with projects, tasks, tags, map/calendar views and batch jobs, export PDF/CSV/JSON/ZIP reports, and use on-device document scanning, OCR, barcode scanning, people-count assistance, and manual counting.

Record mode is limited to in-app capture and freezes key fields at capture time. Integrity packages contain source information, edit history, SHA-256 hashes, and a Secure Enclave or Keychain signature. These features can help detect changes after package creation; they do not prove an absolutely true time, location, or scene and are not represented as court, government, tamper-proof, official-time, or legal certification.

5. Setup and access instructions

No account, login credentials, demo account, subscription, purchase, special configuration, or sample file is required.

  1. Launch the app and tap Shoot (拍摄) on the Home screen.
  2. Allow Camera access. To test detailed-address and nearby-place watermarks, allow Location While Using the App and enable Precise Location.
  3. Use Photo or Video mode. Tap the shutter to take a photo; in Video mode start, pause, resume, and finish recording. Allow Microphone access to include audio. Every capture is previewed before the reviewer chooses retake/re-record or a configured save destination.
  4. Return to Home and tap Import (导入), then choose Import Photo (导入照片) or Import Video (导入视频) and select one item through the system picker.
  5. Open Gallery (相册) to preview or play, edit, share, save, organize, batch-process, report, verify, trash, restore, or permanently delete works. Saving an edit updates the currently opened work; only Save as Copy creates a new work.
  6. Open Settings (设置) to manage shared photo/video templates, capture and save settings, optional iCloud, privacy/security, ads, appearance, support, and local data. Weather attribution is available under Watermark Content and Privacy & Security.
  7. Open the Gallery menu to review Projects, Tags, Map, Calendar, Storage, Reports, Advanced Filters, Batch Operations, and On-device Intelligence.

If Location access is denied, the camera, importing, and all non-location watermark features remain available. If Microphone access is denied, recording remains available without audio. The system picker exposes only the photo or video explicitly selected by the reviewer.

6. External services, tools, and platforms

The app uses Apple-provided frameworks and system services, including optional CloudKit and WeatherKit, plus Google Mobile Ads SDK and Google User Messaging Platform. It has no developer account system, payment or subscription service, custom AI service, or developer-operated media/location backend. Local mode is complete and iCloud sync is off by default.

Apple-provided frameworks and system services include:

  • Apple AVFoundation for camera, audio, video capture, playback, and local export
  • Apple Core Location for the current coordinates
  • Apple CLGeocoder and MapKit local search for detailed-address and nearby-place results
  • Apple PhotosUI and PhotoKit for user-controlled photo/video selection and saving results
  • Apple SwiftData for the local work index; large media remains in Application Support
  • Apple Vision, VisionKit, Core Image, and PDFKit for on-device intelligence and reports
  • Apple CryptoKit, Security, Secure Enclave, and LocalAuthentication for hashes, local signatures, and optional library lock
  • Apple CloudKit for user-initiated private sync and CKShare project collaboration; off by default
  • Apple WeatherKit for user-enabled current-location weather fields; off by default. The app displays  Weather and links to Apple's legal data-sources page.
  • Apple UIKit system share sheet for user-initiated sharing
  • Apple MessageUI or the user's installed Mail app for optional feedback
  • Apple StoreKit for the system App Store rating request

Google Mobile Ads SDK supplies app-open, native, banner, interstitial, rewarded, and rewarded-interstitial advertising. Google User Messaging Platform manages consent and advertising privacy choices where applicable. UMP does not replace Apple's ATT permission. The ATT decision is resolved before the Mobile Ads SDK starts or requests an ad; Google can access IDFA only when tracking is authorized. Google advertising services may process device identifiers, IP address, advertising interactions, and diagnostics according to the user's choices and Google's policies.

All watermark composition, editing, OCR, scanning, barcode processing, people detection, counting, hashing, signing, and report generation are performed locally. Location and weather queries are handled by Apple services. If the user enables iCloud, selected project data, metadata, location fields, and optional media are stored in the user's Apple iCloud private database; CKShare exposes a chosen project only to participants invited by the user.

App Privacy disclosure must include the data types declared by Google Mobile Ads (coarse location, crash data, performance data, product interaction, device ID, advertising data, and other diagnostics) and the optional iCloud functionality (photos or videos, precise location, other user content, and other app data for App Functionality). Device ID is used for tracking only as disclosed by Google's SDK and is gated by ATT. iCloud content is linked for App Functionality and is not used for tracking.

7. Regional differences

The app's core functions are available consistently in all regions, with no region-locked features or paid content. The interface supports Simplified Chinese and English. Ad consent and privacy options may vary by applicable law and Google UMP requirements. Ad availability, WeatherKit results, address language, nearby-place detail, and iCloud availability can vary according to network, Apple service availability, account state, map coverage, device language, and location accuracy.

If a detailed place name is unavailable, users can still use date, time, weekday, coordinates, device information, and custom-text watermarks.

8. Regulated industry and protected third-party material

The app is a general camera and photo/video-editing utility. It does not provide medical, financial, legal, gambling, transportation-booking, or government services. It does not bundle, sell, stream, or publish protected third-party material.

The app processes only photos and videos captured by the user or explicitly selected by the user through the system picker. Integrity hashes and device-local signatures are not represented as tamper-proof proof, court or government certification, official time, absolute location, or legal certification. No regulatory authorization, third-party media license, demo account, or external credential is required.
