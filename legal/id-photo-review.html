3. Functions, target audience, problem, and value

ID Photo Studio is a Simplified Chinese photo utility for users who need portraits in common document, school, employment, resume, travel, application, or visa-photo proportions.

Apple Vision identifies the person and face on the device. The app removes or replaces the background, frames the portrait, and creates a PNG using a preset or user-entered custom size. The result can be saved to Photos or Files, or shared through the iOS system share sheet.

The app provides a quick way to prepare a clean, correctly proportioned portrait without sending the user's photo to an external server.

4. Setup and access instructions

No account, login credentials, subscription, purchase, activation, special configuration, or sample file is required. Any clear, front-facing portrait may be used.

  1. Launch the app and tap Choose Photo (选择照片).
  2. Select one clear portrait in the iOS system photo picker.
  3. Wait for the on-device person-recognition process to finish.
  4. Select a preset size, or enter width and height under Custom Size (自定义尺寸), then choose a background color.
  5. Tap Generate ID Photo (生成证件照).
  6. Select Save to Photos (保存到照片), Save to Files (保存到文件), or Share with Other Apps (分享给其他应用).

The iOS system photo picker provides only the image explicitly selected by the user. Add-only Photos permission is requested only when the user chooses to save the generated result to Photos. No camera, microphone, location, contacts, or App Tracking Transparency permission is requested.

5. External services, tools, and platforms

The app does not use third-party SDKs, a developer-operated server, authentication providers, payment processors, advertising platforms, analytics services, data providers, or third-party AI services. It does not upload user photos.

It uses only Apple system services and frameworks:

  • Apple Vision for on-device person and face detection
  • Apple PhotosUI for user-controlled photo selection
  • Apple Photos for saving a generated result
  • Apple UIKit for the system share sheet
  • Apple StoreKit for the system App Store review request
  • The system Mail app for optional user feedback

6. Regional differences

The app functions consistently in all available regions. It has no region lock, country-specific service, or region-specific feature availability. The current user interface is Simplified Chinese.

7. Regulated industry and protected third-party material

ID Photo Studio is a general photo-editing utility. It does not issue identification, verify identity, submit applications to government authorities, or claim government affiliation. Preset names are photo-size references only, and users are advised to confirm the receiving organization's current requirements.

The app does not contain protected third-party material. No regulatory authorization, third-party license, demo account, or external credential is required.
