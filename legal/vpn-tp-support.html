VPN TP 技术支持

如何联系我们

技术支持与用户反馈统一使用 2223140373@qq.com。你可以直接发送邮件，也可以在 iPhone、iPad 或 Mac 版中进入“设置 → 关于 → 技术支持与反馈”；系统邮件会自动填写收件人、App 版本和系统版本，但不会自动附加任何配置、凭据或诊断文件。请补充设备型号、输入格式、操作步骤和问题截图；发送前完全脱敏，不要附上真实密码、Token、私钥、PSK、证书或可用配置。

VPN TP 能连接 VPN 或提供线路吗？

不能。VPN TP 是配置解析、编辑、检查和转换工具，不建立系统 VPN 连接，不使用 NetworkExtension，不提供服务器、公共节点或订阅市场，也不代理或转发流量。订阅 URL 功能只从你选择的 HTTPS 服务商下载配置文本，不提供连接能力。

如何一键看到完整的示例界面？

打开“设置 → 展示数据 → 添加安全示例”，或点击工作台空状态中的示例入口。应用会加入 11 条本地演示数据，它们仅使用保留域名、文档专用 IP 和无效测试凭据，不包含可用节点。

支持哪些订阅和导入格式？

应用可从用户提供的公网 HTTPS 订阅 URL 识别 URI 列表、整包 Base64、Clash YAML 和 Sing-box JSON，也可直接导入常见配置 URI、JSON、YAML、CSV、WireGuard 与 OpenVPN 文本。常见协议包括 Shadowsocks/SSR、VMess、VLESS、Trojan、Hysteria/Hysteria 2、TUIC、SOCKS、HTTP/HTTPS、SSH、WireGuard、OpenVPN、IKEv2、IPSec、L2TP 与 PPTP。订阅可一键导入并自动建立来源分组，粘贴、文件和二维码也可直接保存；需要筛选时仍可使用预览。

如何区分节点来自哪个订阅？

每个订阅 URL 会自动对应一个独立分组。导入完成后可从结果弹窗直接打开该分组；配置库列表会显示分组名称，节点详情与“设置 → 分组与标签”会显示脱敏来源。为保护服务商凭据，路径或查询中的疑似 Token 会隐藏，完整订阅 URL 不会写入数据库。同一订阅再次导入会更新其中的匹配节点；不同订阅包含相同节点时仍分别归组。

为什么某个订阅 URL 不能下载？

VPN TP 只接受公网 HTTPS 地址，拒绝 HTTP、带内嵌账号密码的 URL、本机和私网 IP；请求最多等待 30 秒，响应上限为 10 MB。App 不后台刷新订阅，也不会对仅含 proxy-providers 引用的 YAML 静默递归下载其他地址。请确认服务商允许直接访问、证书有效、返回 UTF-8 配置文本并直接包含节点，然后检查当前网络。URL 中由服务商签发的路径或 Token 会直接发送给该服务商，请勿把真实订阅 URL 发给技术支持。

如何查看详情并分享二维码？

点击工作台底部“最近编辑”或配置库里的任意项目即可进入详情，再选择“分享链接或二维码”。默认内容已脱敏，可复制/分享 URL 或配置文本，也可分享、保存二维码图片。包含完整密码和凭据需要二次确认并通过 Face ID、Touch ID 或设备密码验证；请只发送给可信任的接收者。

为什么转换后有些字段没有保留？

不同配置格式的能力并不完全相同。VPN TP 会在生成结果前列出无法转换或将被忽略的字段。请检查兼容性提示，不要把格式转换结果直接视为网络可用性或安全保证。

如何切换界面语言？

进入“设置 → 通用 → App 语言”，选择跟随系统或 10 种内置语言，包括新增的 Русский（俄语）与 فارسی（波斯语）。更改会立即应用并保存在本机，波斯语自动使用从右向左布局；如系统弹窗仍显示系统语言，这是 iOS、iPadOS 或 macOS 管理的界面。

Mac 版有哪些桌面操作？

Mac 版提供左侧边栏、可调整窗口和右上角 VPN TP 菜单栏入口。菜单栏可查看配置统计、快速进入工作台、配置库、导入、工具和设置，或添加安全示例；Command-1 至 Command-5 分别进入五个页面，Command-Shift-D 可载入安全示例。若不需要菜单栏入口，可在“设置 → 通用”关闭。

备份密码忘记了怎么办？

完整备份使用 AES-GCM 加密，应用不会保存密码，开发者也无法恢复。请妥善保管密码；仍能进入原设备时，可使用新密码重新创建备份。

相机、照片或 Face ID 为什么会被请求？

相机仅用于主动扫描二维码；照片仅处理通过系统选择器选中的二维码图片或保存用户生成的二维码；Face ID、Touch ID 或设备密码仅用于保护敏感字段和完整导出。首次启动不会请求这些权限。

为什么会显示广告或跟踪权限？

免费 iPhone 与 iPad 版使用 Google Mobile Ads 和 UMP，可能展示横幅、原生、插页或开屏广告。适用地区会先显示 Google 隐私选择，随后可能显示 Apple ATT 权限；App 会等待 ATT 结果后再请求广告。同时允许个性化用途与 ATT 时可获得符合条件的个性化广告。拒绝任一选择不会限制配置功能，广告仍可能按 UMP 状态以不使用 IDFA 的非个性化、受限或技术投放方式展示。导入的配置、凭据和检查结果不会发送给 Google。原生 Mac 版不含广告或 ATT。

如何分享或评价 VPN TP？

进入“设置 → 关于”，可通过“分享 VPN TP”发送正式 App Store 链接；“为 VPN TP 评分”调用 Apple 系统评分界面；“前往 App Store 写评价”则直接打开评论页。App 也会在多次使用并完成导入、保存、导出或备份后智能请求系统评分，同一版本最多请求一次，并设置跨版本冷却期。系统评分弹窗是否显示仍由 Apple 根据设备与调用频率决定；判断所需计数仅保存在当前设备，不会上传。
