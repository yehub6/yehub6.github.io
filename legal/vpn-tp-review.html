产品边界

  • VPN TP 是离线优先的网络配置解析、编辑、检查和转换工具。
  • App 不提供 VPN 服务，不创建系统 VPN 配置，不提供服务器、公共节点、免费线路、订阅市场或远程订阅下载。
  • 工程不使用 NetworkExtension、NEVPNManager 或 NETunnelProviderManager，没有 Packet Tunnel Target 或 Personal VPN entitlement。
  • App 不出售流量或线路，不代理或转发用户网络流量。

建议审核路径

  1. 完成四页首次启动引导，无需登录。
  2. 打开“设置 → 展示数据”，点击“添加安全示例”。App 会载入 11 条本地示例，仅使用保留域名、文档专用 IP 地址段和无效测试凭据。
  3. 打开“配置库”，查看、编辑、收藏、分组或删除示例配置。
  4. 打开“导入”，粘贴 trojan://example-password@example.com:443#Review%20Example，点击“识别并检查”，再保存所选项目。
  5. 打开“工具 → 配置脱敏”，粘贴上述文本并查看标准脱敏结果。
  6. 在“配置比较”和“格式转换”中检查统一字段、敏感字段隐藏、兼容性提示与输出预览。
  7. 打开“二维码生成”。默认生成脱敏二维码；包含敏感字段时会先警告并请求设备身份验证。
  8. 在“设置 → 通用 → App 语言”选择任意语言，确认界面立即切换。
  9. “设置 → 创建加密备份”可验证密码备份与恢复流程；备份密码不会保存。

Mac 审核提示

Mac 版为原生 macOS target，左侧边栏可直接进入五个主要页面，窗口支持调整大小；右上角菜单栏使用 VPN TP 正式 AppIcon，提供配置统计、页面直达、添加安全示例和退出操作，菜单命令提供 Command-1 至 Command-5 页面快捷键与 Command-Shift-D 安全示例快捷键。它与 iPhone / iPad 版本共用 Bundle ID com.vpntp，但不提交 Catalyst 兼容构建。

展示数据说明

内置示例只用于本地演示，不包含实时订阅、可用服务器或可连接凭据。示例可一键添加和删除，不会从网络下载，也不会与用户真实数据混合上传。

权限说明

  • 相机：仅在审核人员主动扫描二维码时请求。
  • 照片：仅处理通过系统选择器明确选中的图片，或在用户主动操作时保存二维码。
  • Face ID / Touch ID / 设备密码：用于保护敏感字段、敏感二维码与完整导出。
  • 通知：仅在用户主动开启每月本地备份提醒时请求。

网络与隐私

配置解析、验证、脱敏、比较、转换、二维码和保存均在设备本地完成。App 没有自有配置服务器、账号系统、广告、行为分析或跨应用跟踪。DNS、TCP 与 TLS 检查只访问审核人员主动输入的地址，不建立代理或转发流量。

本地化

App 支持 English、简体中文、繁體中文、日本語、한국어、Español、Français 与 Deutsch，并可跟随系统语言。语言选择保存在当前设备并即时生效。
